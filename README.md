# English — шаг за шагом

Приложение: https://evgk724.github.io/english-instructions-ryan-pages/

12 английских выражений для инструкций и объяснений: крупные карточки, русский смысл, примеры и учебная озвучка Microsoft Ryan.

Листайте в сторону или нажимайте стрелки. «Слушать» запускает выражение и пример, повторное нажатие ставит паузу. Для работы без интернета нажмите «Сохранить офлайн» и дождитесь подтверждения загрузки всего набора.

На iPhone откройте страницу в Safari → Поделиться → На экран Домой. Если пункт скрыт, используйте «Изменить действия» внизу меню. После добавления откройте приложение с иконки и проверьте офлайн-сохранение ещё раз.

Выражения основаны на коротком учебном блоке Englex. Русские пояснения и новые примеры подготовлены для этой подборки. Исходные фотографии и полный курс здесь не публикуются. Голос: Microsoft `en-GB-RyanNeural`. Шрифт Golos: лицензия в `site/fonts/OFL.txt`.

Если вы раньше использовали другой адрес приложения, на этом адресе сохраните офлайн-набор заново: данные хранятся отдельно для каждого сайта.
